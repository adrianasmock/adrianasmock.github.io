Pricing & Profitability Dashboard

Did the price increase pay off, how much of the growth came from price vs. volume, and where is the brand priced against competitors? This report breaks sales growth into price, volume and mix, and measures how shoppers responded to a March 2026 price increase.

Saltbrush Snack Co. is a fictional brand. Every number on this page comes from an invented dataset, not from an employer or client.
Power BIDAXPrice-volume-mixPrice elasticityRevenue management

What the report answers

  • A price-volume-mix bridge from last year's retail sales to this year's
  • Volume response to the price increase, using an unchanged product line as the control
  • Price index vs. competitors by product line
  • Price realization, net price and contribution per unit by retailer

What the sample data shows

Retail sales grew $766K: price added $99K and volume $668K. The March increase on Kettle Chips (+6%) and Popcorn (+5%) lifted contribution per unit from $0.56 to $0.69 and from $0.86 to $0.96, and base velocity barely moved (measured elasticity −0.7 and −0.5, using Tortilla Chips as the control). Tortilla Chips were not increased and now sit 7% below competitors, which is the next pricing opportunity.

Data model

A star schema: one fact table with the numbers, and dimension tables for filtering. Relationships are one-to-many from each dimension to the fact table on its ID or key column.

TableContents
fact_retail_salesWeek × retailer × SKU: units, dollars, stores selling, promo flag, average and list shelf price
fact_price_listSKU list price history with effective dates
fact_competitor_priceMonth × product line: average competitor shelf price
fact_sku_pnlMonth × customer × SKU P&L, used for net price and contribution per unit
dim_week · dim_product · dim_retailerShared dimensions; competitor prices join on product line

Key DAX measures

Retail $ = SUM ( fact_retail_sales[Dollars] )
Units    = SUM ( fact_retail_sales[Units] )
-- Retail $ YA and Units YA shift the fiscal week window back 52 weeks (see the sell-through sample)

Avg Shelf Price = DIVIDE ( [Retail $], [Units] )

Price Realization =
DIVIDE ( [Retail $], SUMX ( fact_retail_sales, fact_retail_sales[Units] * fact_retail_sales[ShelfListPrice] ) )

-- Price-volume-mix, calculated at SKU x retailer grain
Avg Price YA = DIVIDE ( [Retail $ YA], [Units YA] )

Price Effect =
SUMX (
    CROSSJOIN ( VALUES ( dim_product[SKU] ), VALUES ( dim_retailer[RetailerID] ) ),
    VAR P0 = [Avg Price YA]
    RETURN IF ( ISBLANK ( P0 ), 0, [Retail $] - P0 * [Units] )
)

Volume Effect = ( [Units] - [Units YA] ) * [Avg Price YA]

Mix Effect =
SUMX (
    CROSSJOIN ( VALUES ( dim_product[SKU] ), VALUES ( dim_retailer[RetailerID] ) ),
    [Avg Price YA] * [Units]
) - [Units] * [Avg Price YA]

-- Regular (list) shelf price vs. the average competitor shelf price; 100 = parity
Price Index =
DIVIDE (
    DIVIDE ( SUMX ( fact_retail_sales, fact_retail_sales[Units] * fact_retail_sales[ShelfListPrice] ), [Units] ),
    AVERAGE ( fact_competitor_price[CompetitorShelfPrice] )
) * 100

-- Velocity without promotion weeks, used to read the price response
Base Velocity =
CALCULATE ( DIVIDE ( [Units], SUM ( fact_retail_sales[StoresSelling] ) ), fact_retail_sales[PromoFlag] = 0 )

Net Price per Unit =
DIVIDE (
    SUM ( fact_sku_pnl[GrossSales] ) - SUM ( fact_sku_pnl[OffInvoice] ) - SUM ( fact_sku_pnl[ScanDown] )
        - SUM ( fact_sku_pnl[Slotting] ) - SUM ( fact_sku_pnl[Spoilage] ),
    SUM ( fact_sku_pnl[Units] )
)
