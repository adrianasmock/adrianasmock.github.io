Trade Spend & Margin Dashboard

Where does gross sales go before it becomes profit, which customers cost the most in trade, and do promotions pay for themselves? This report walks from gross to net to gross profit for each customer.

Saltbrush Snack Co. is a fictional brand. Every number on this page comes from an invented dataset, not from an employer or client.
Power BIDAXGross-to-netTrade promotionCustomer P&L

What the report answers

  • A gross-to-net waterfall: off-invoice, scan-downs, slotting, spoilage and COGS
  • Trade spend as a % of gross by customer, against the average
  • Gross margin % by customer
  • A customer P&L with promotion ROI

What the sample data shows

Trade spend is 10.6% of gross sales and gross margin is 40.2%. Corner Convenience and Mountain Market spend the most on trade, and their promotions lose money (–48% and –30% ROI), while Summit Grocery's promotions return +25%. That points to moving promo dollars rather than cutting them.

Data model

A star schema: one fact table with the numbers, and dimension tables for filtering. Relationships are one-to-many from each dimension to the fact table on its ID or key column.

TableContents
fact_trade_pnlMonth × customer: units, gross sales, off-invoice, scan-down spend, slotting, spoilage, COGS, incremental promo units
dim_retailerCustomer, channel, total stores

Key DAX measures

Gross Sales = SUM ( fact_trade_pnl[GrossSales] )

Trade Spend =
SUM ( fact_trade_pnl[OffInvoice] ) + SUM ( fact_trade_pnl[ScanDownSpend] )
    + SUM ( fact_trade_pnl[Slotting] ) + SUM ( fact_trade_pnl[Spoilage] )

Net Sales     = [Gross Sales] - [Trade Spend]
Gross Profit  = [Net Sales] - SUM ( fact_trade_pnl[COGS] )
Gross Margin %  = DIVIDE ( [Gross Profit], [Net Sales] )
Trade % of Gross = DIVIDE ( [Trade Spend], [Gross Sales] )

-- Gross profit per unit before trade, applied to the extra units a promotion sold
Incremental Promo GP =
SUM ( fact_trade_pnl[IncrementalUnits] )
    * DIVIDE ( [Gross Sales] - SUM ( fact_trade_pnl[COGS] ), SUM ( fact_trade_pnl[Units] ) )

Promo ROI =
DIVIDE (
    [Incremental Promo GP] - SUM ( fact_trade_pnl[ScanDownSpend] ),
    SUM ( fact_trade_pnl[ScanDownSpend] )
)
